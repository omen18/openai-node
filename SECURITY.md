# Security Policy

## Reporting Security Vulnerabilities

If you believe you have discovered a security vulnerability in the OpenAI Node.js SDK or related OpenAI services, please report it through OpenAI's official vulnerability disclosure program:

1. **Bug Bounty Program**: Report through [Bugcrowd](https://bugcrowd.com/openai).
2. **Private Disclosure**: If you cannot report via Bugcrowd, contact `security@openai.com`.

**Please do NOT disclose vulnerability details in public GitHub issues, discussions, or pull requests.**

### What to Include

When reporting a vulnerability, please provide:
- A detailed description of the issue.
- Minimal reproduction code or steps.
- The environment and SDK version in which the issue was observed.
- Potential impact and any suggested mitigations.

We appreciate responsible security research and will work to address confirmed issues promptly.
